# የሕዝብ ተጠቃሚ መመሪያ

ወደ ጂማ እስላማዊ ምክር ቤት የማህበረሰብ ፖርታል እንኳን በደህና መጡ። ይህ መመሪያ በሕዝብ ገጾች ላይ ያሉ ዋና ዋና ባህሪያትን እንዴት እንደሚጠቀሙ ያብራራል። የሕዝብ ገጾችን ለማየት ወይም የሕዝብ አገልግሎት ቅጾችን ለመሙላት የሠራተኛ መለያ አያስፈልግም።

## ተቋም ወይም አካባቢ መፈለግ

1. ከዋናው አሰሳ ውስጥ **ተቋማት** የሚለውን ይክፈቱ።
2. **መስጊዶች**, **መድረሳዎችና ሂፍዝ**, **መምህራንና ሙዓሊሞች**, ወይም **ዑለማ ሊቃውንት** ይምረጡ።
3. በማውጫው ውስጥ ይፈልጉ ወይም ያስሱ፤ ያለውን የመገለጫና የመገኛ መረጃ ለማየት አንድ ዝርዝር ይክፈቱ።
4. ቦታዎችንና አካባቢዎችን በካርታ ለማየት **የቀበሌ ካርታን ያስሱ** የሚለውን ይምረጡ።

## ለሕዝብ አገልግሎት ማመልከት

1. [የሕዝብ አገልግሎቶች](/services) ይክፈቱ፤ በአገልግሎት ማውጫው ውስጥ ያስሱ ወይም ይፈልጉ።
2. መጀመሪያ የአገልግሎቱን ዝርዝር ይክፈቱ። የብቁነት መስፈርቶችን፣ ደረጃዎችን፣ አስፈላጊ ሰነዶችን፣ ክፍያውንና የሚጠበቀውን የሂደት ጊዜ ይመልከቱ።
3. የኦንላይን ማመልከቻ ክፍት ከሆነ **ያመልክቱ** ወይም **ወደ ኦንላይን ማመልከቻ ይቀጥሉ** የሚለውን ይምረጡ።
4. ቅጹን ሞልተው ያስገቡ። ከቀረበ በኋላ የሚታየውን የማመልከቻ መለያ ያስቀምጡ፤ ሁኔታውን ሲከታተሉ ተመሳሳይ የስልክ ቁጥር ይጠቀሙ።

አንዳንድ የተዘረዘሩ ሰነዶች በቃለ መጠይቅ ጊዜ በአካል ሊቀርቡ ይችላሉ፤ የአገልግሎቱን ዝርዝር ይመልከቱ። ለአንድ አገልግሎት የኦንላይን ማመልከቻ ሊዘጋ ይችላል። ቅጹ ካልተከፈተ፣ በጣቢያው ላይ ያለውን የምክር ቤቱን የመገኛ መረጃ ይጠቀሙ።

### የዘካ ድጋፍ

በአገልግሎት ማውጫው ውስጥ **የዘካ ድጋፍ** ይምረጡ። የአመልካቹን ስም፣ ስልክ ቁጥር፣ ቀበሌ፣ የቤተሰብ አባላት ብዛትና አስፈላጊ የብቁነት ማብራሪያዎችን ያስገቡ። ካስገቡ በኋላ የማመልከቻ መለያውን ያስቀምጡ። ሁኔታውን ለመመልከት **ማመልከቻን ይከታተሉ** ይክፈቱ፤ መለያውንና ተመሳሳይ ስልክ ቁጥር አስገብተው ያስገቡ።

### የጃናዛ ድጋፍ

**የጃናዛ ድጋፍ** ይምረጡ፤ የቤተሰብ መገናኛ ሰው ስምና ስልክ፣ የሟቹን ሙሉ ስምና ቀበሌ ያስገቡ። የሚፈልጉትን ድጋፍ (ጉስል/ከፈን፣ መጓጓዣ ወይም የመቃብር ቦታ) ይምረጡ፤ ስለ ቦታው ወይም ስለ መነሻ ቦታው ግልጽ ማብራሪያ ይጨምሩ። የጥያቄ መለያውን ያስቀምጡ፤ የተጠሪው ባለሙያ ሊያገኝዎ ስለሚችል ስልክዎን ክፍት ያድርጉ። መለያውንና የመገናኛ ስልኩን በመጠቀም ይከታተሉ። የኦንላይን የጃናዛ ማመልከቻ ካልተከፈተ፣ በምክር ቤቱ የተዘረዘረውን የ24 ሰዓት የአደጋ ጊዜ ስልክ ይጠቀሙ።

### ሌሎች የአገልግሎት ጥያቄዎች

ለዚያ አገልግሎት በዝርዝሩና በማመልከቻ ቅጹ የቀረቡትን መመሪያዎችና አስፈላጊ ሰነዶች ይከተሉ። የተሰጠውን መለያ ያስቀምጡ። መለያው በመከታተያው ውስጥ ካልተገኘ፣ በጣቢያው ያለውን የአገልግሎት ዴስክ መገኛ መረጃ ይጠቀሙ።

## ዝግጅቶች፣ ምዝገባና የመግቢያ ፓስ

1. [ዝግጅቶች](/events) ይክፈቱ። በቁልፍ ቃል ይፈልጉ ወይም በምድብ፣ በቀበሌ ወይም በምዝገባ ሁኔታ ያጣሩ። ቀኑን፣ ሰዓቱን፣ ቦታውን፣ አቅሙንና መስፈርቶቹን ለማየት ዝግጅቱን ይክፈቱ።
2. ምዝገባው ክፍት ከሆነ **RSVP / ይመዝገቡ** ይምረጡ፤ የተሳታፊውን ሙሉ ስም፣ ስልክ፣ ኢሜይልና ሌሎች የምዝገባ መረጃዎችን ያስገቡ።
3. ነፃ ለሆነ ዝግጅት ቅጹን ያስገቡ። ከተቀበለ፣ ፓስ ይሰጣልና ከማረጋገጫው ማየት ይችላሉ።
4. ለክፍያ የሚጠይቅ ዝግጅት፣ የዝግጅቱን የክፍያ መመሪያ ይከተሉና ደረሰኙን ከምዝገባው ጋር ይጫኑ። የምክር ቤቱ ክፍያውን እስኪያጸድቅ ድረስ ምዝገባው በግምገማ ላይ ይቆያል፤ ከጸደቀ በኋላ የመግቢያ ፓስ ይሰጣል።
5. የፓስ ቁጥሩንና ኢሜይሉን ያስቀምጡ። ያሉ ፓሶችን ለማግኘት **የእኔ ፓሶች** ይጠቀሙ፤ በምዝገባ የተጠቀሙትን ኢሜይልና ስልክ ያስገቡ። ፓሶችን ከዚያ ማውረድ ወይም ማተም ይችላሉ።

ዝግጅቱ ከሞላ፣ ከተሰረዘ ወይም ምዝገባው ከተዘጋ፣ ፖርታሉ አዲስ ምዝገባ አይቀበልም።

## የዝግጅትና የአሳሽ ማሳወቂያዎች

1. በዝግጅቶች ገጽ ላይ **ለማሳወቂያ ይመዝገቡ** ወይም **ምርጫዎችና ማጣሪያዎች** ይምረጡ።
2. ኢሜይል እና/ወይም የአሳሽ ማሳወቂያ ይምረጡ፤ የዝግጅት ምድቦችን፣ ቀበሌዎችንና የማስታወሻ ጊዜን ያዘጋጁ።
3. የኢሜይል ማሳወቂያዎች ከመላካቸው በፊት በተላከልዎት አገናኝ ኢሜይልዎን ያረጋግጡ።
4. ለርቀት የአሳሽ ማሳወቂያ፣ ለጣቢያው የማሳወቂያ ፈቃድ ይስጡ፤ በእያንዳንዱ መሣሪያ ማሳወቂያዎችን ያንቁና ምርጫዎቹን ያስቀምጡ።
5. **የርቀት የማሳወቂያ ሙከራ ይላኩ** የሚለውን በመጠቀም በአሁኑ ጊዜ የተመዘገበውን አሳሽ ብቻ ይሞክሩ። የስኬት መልዕክቱ የግፊት አገልግሎቱ ጥያቄውን መቀበሉን ያሳያል፤ ማሳወቂያውን ለማየት የዚያን መሣሪያ የማሳወቂያ ማዕከል ይመልከቱ።

ከተመሳሳይ የምርጫ ገጽ ምርጫዎችን ማዘመን ወይም ምዝገባዎን ማስወገድ ይችላሉ። የአሳሽ ፈቃድን በአሳሹ የጣቢያ ቅንብሮች ውስጥም መቀየር ይችላሉ።

2. ከተዘረዘሩት የክፍያ ዘዴዎች አንዱን ይምረጡና የተላለፈ ክፍያ መመሪያዎቹን ያንብቡ።
3. የልገሳ ጥያቄውን ያረጋግጡና የማጣቀሻ ቁጥሩን ያስቀምጡ።
4. በተለየ ሁኔታ ክፍያውን በታየው መመሪያ መሠረት ያጠናቅቁ፤ የክፍያ ማስረጃዎን ይያዙ። ፖርታሉ ጥያቄን ይመዘግባል፤ ማረጋገጫው **የክፍያ ደረሰኝ ወይም ክፍያው መረጋገጡን የሚያሳይ ማስረጃ አይደለም**። የምክር ቤቱ ክፍያውን እስኪያረጋግጥ ይጠብቁ።

### ዘካ ወይም ኡሽር ማስላት

1. ከላይ ካለው ማውጫ፣ ከአገልግሎቶች ገጽ ወይም ከ[ልገሳ](/donate?tab=zakat-calculator) **የዘካ ማስያ** ይክፈቱ።
2. ለጥሬ ገንዘብ፣ ለባንክና ዲጂታል ቀሪ ሂሳቦች፣ ለወርቅ ወይም ለብር፣ ለንግድ ንብረት፣ ለኢንቨስትመንት፣ ለሰብል ወይም ለእንስሳት አስፈላጊውን መጠንና ብዛት ያስገቡ፤ የሚመለከቱ የአጭር ጊዜ ዕዳዎችንና አስቸኳይ የኑሮ ወጪዎችንም ያክሉ።
3. የሚታየውን የኒሳብ መጠንና የስሌት ውጤት ይመልከቱ። ትርጓሜና ግምቶችን ለማወቅ በማስያው የሸሪዓ መመሪያን ይጠቀሙ።
4. ግምገማን በታሪክ ውስጥ ለማስቀመጥና በኋላ እንደገና ለመክፈት ወደ ተጠቃሚ መለያ ይግቡ። ማስያውን ማየትና ማስላት መግባትን አይጠይቅም።

ማስያው ለግምት የሚያግዝ መሣሪያ ነው፤ ክፍያ፣ ኦፊሴላዊ ማመልከቻ ወይም የግል የሃይማኖት ውሳኔ አይደለም። ንብረትን እንዴት እንደሚመድቡ ካልተረጋገጡ፣ ብቁ ዑለማን ወይም የምክር ቤቱን የዘካ ዴስክ ያማክሩ።

## ማስታወቂያዎችና የወቅፍ መረጃ

- ማስታወቂያዎችን ለመፈለግና በቅድሚያ ደረጃ ለማጣራት [ማስታወቂያዎች](/announcements) ይክፈቱ። የገጹን አገናኝ ለመቅዳት **አጋራ** ይጠቀሙ።
- በወቅፍ ማውጫ የታተመውን መረጃ ለማየት ከአገልግሎቶች ማውጫ **የወቅፍ ግልጽነት** ይክፈቱ።

## መገናኛ፣ ቋንቋና ተደራሽነት

- የምክር ቤቱን የመገናኛ ዴስኮችና ተደጋጋሚ ጥያቄዎችን ለማየት [ያግኙን](/contact) ይክፈቱ። ይፋዊ ጥያቄ ለማስገባት ስምዎንና ስልክዎን ያስገቡ፣ የጥያቄውን ምድብና የምክር ቤቱን ዴስክ ይምረጡ፣ ከዚያም ጥያቄዎን ይግለጹ። ኢሜይል አማራጭ ነው። ካስገቡ በኋላ የጥያቄውን ማጣቀሻ ቁጥር ያስቀምጡ። ሁኔታውን በኋላ ለማየት **ይፋዊ ጥያቄን ይከታተሉ** በሚለው ቦታ የማጣቀሻ ቁጥሩንና በማመልከቻው የተጠቀሙትን ስልክ ቁጥር ያስገቡ፤ የጥያቄ መረጃን ለመጠበቅ ሁለቱም ያስፈልጋሉ።
- ቋንቋ ለመምረጥ በራስጌው ያለውን የቋንቋ መምረጫ ይጠቀሙ። በብርሃንና በጨለማ ገጽታ መካከል ለመቀየር የገጽታ ቅንብሩን ይጠቀሙ።
- የሠራተኛ መግቢያ ለተፈቀደላቸው የምክር ቤት ሠራተኞች ብቻ ነው። የሕዝብ አገልግሎቶችን፣ ማውጫዎችን፣ ዝግጅቶችን፣ ማስታወቂያዎችንና የዘካ ማስያውን ለመጠቀም የሠራተኛ መግቢያ አያስፈልግም።

## የማመልከቻ መለያዎችዎን ይጠብቁ

የጥያቄና የማመልከቻ ማጣቀሻ ቁጥሮችን፣ የክፍያ ማጣቀሻዎችን፣ የዝግጅት ፓስ ቁጥሮችንና በማመልከቻ የተጠቀሙትን ስልክ/ኢሜይል ያስቀምጡ። የግል የኢሜይል ማረጋገጫ አገናኞችን ወይም የማሳወቂያ አስተዳደር አገናኞችን ለሌሎች አያጋሩ።
