# Qajeelfama Fayyadamaa Ummataa

Gara poortaala hawaasaa Mana Maree Islaamaa Jimmaa dhuftan. Qajeelfamni kun fuula ummataa irratti argaman akkamitti akka fayyadamtan ibsa. Fuula ummataa ilaaluuf ykn unka tajaajila ummataa guutuuf herrega hojjettootaa hin barbaachisu.

As deebi'uuf sarara gubbaa irraa **Qajeelfama Fayyadamaa** fili. Bilbila irratti, menu navigeeshinii bani.

## Dhaabbata ykn naannoo barbaaduu

1. Navigeeshinii ijoo keessaa **Dhaabbilee** bani.
2. **Masjiidota**, **Madrasoota fi Hifz**, **Barsiisota fi Mu'allimoota**, ykn **Hayyoota Ulamaa** keessaa fili.
3. Galmee keessa barbaadi ykn daawwadhu; odeeffannoo jiru fi quunnamtii argachuuf galmee tokko bani.
4. Bakkaalee fi naannolee kaartaan ilaaluuf **Kaartaa Kebele qoradhu** fili.

## Tajaajila ummataa gaafachuu

1. [Tajaajiloota Ummataa](/services) bani; galmee tajaajilaa keessa qoradhu ykn barbaadi.
2. Dura ibsa tajaajilaa bani. Ulaagaa, tarkaanfiiwwan, sanadoota barbaachisan, kaffaltii fi yeroo tilmaamaa ilaali.
3. Yoo galmeen karaa interneetii banaa ta'e **Iyyadhu** ykn **Iyyata Karaa Interneetii** fili.
4. Unka guutii ergi. Lakkoofsa wabii erga mul'ate booda kuusii; haala iyyata kee ilaaluuf lakkoofsa bilbilaa quunnamtii sana fayyadami.

Sanadoonni tarreeffaman tokko tokko yeroo gaaffii/ilaalcha qaamaan dhiyaachuu qabu ta'a; kanaaf ibsa tajaajilaa ilaali. Tajaajilli tokko iyyata karaa interneetii fudhachuu dhaabuu danda'a. Unki yoo hin banamne, odeeffannoo quunnamtii mana maree fuula irratti jiru fayyadami.

### Deeggarsa Zakaa

Galmee tajaajilaa keessaa **Deeggarsa Zakaa** fili. Maqaa iyyataa, lakkoofsa bilbilaa, kebele, baay'ina maatii fi yaada ulaagaa barbaachisaa yoo jiraate galchi. Erga ergitee booda lakkoofsa wabii kuusii. Haala isaa ilaaluuf **Iyyata Hordofi** bani; wabii fi lakkoofsa bilbilaa sana galchii ergi.

### Deeggarsa Janaazaa

**Deeggarsa Janaazaa** fili; maqaa fi bilbila nama quunnamtii maatii, maqaa guutuu nama du'ee fi kebele galchi. Deeggarsa barbaaddu (Ghusl/uffisa awwaalchaa, geejjibaa, ykn iddoo awwaalchaa) fili; bakka ykn bakka ka'umsaa sirriitti ibsi. Wabii gaaffii kuusii; bilbilli kee waamicha hojjetaa yeroo-dhiyoo eeguu haa danda'u. Wabii fi lakkoofsa bilbila quunnamtii fayyadamuun haala hordofi. Iyyanni Janaazaa karaa interneetii yoo hin jirre, lakkoofsa bilbila hatattamaa sa'aatii 24 tajaajilu kan mana maree irratti tarreeffame fayyadami.

### Gaaffilee tajaajila biroo

Tajaajila sanaaf qajeelfama, sanadoota fi unka iyyataa ibsa tajaajilaa keessatti kenname hordofi. Wabii yoo siif kenname kuusii. Wabiin hordoffii keessatti yoo hin argamne, odeeffannoo quunnamtii kutaa tajaajilaa fayyadami.

## Sagantaawwan, galmee fi paasii seensaa

1. [Sagantaawwan](/events) bani. Jecha barbaadduun qoradhu ykn ramaddii, kebele, ykn haala galmee irratti calali. Guyyaa, sa'aatii, bakka, dandeettii fi ulaagaalee ilaaluuf sagantaa bani.
2. Galmeen yoo banaa ta'e **RSVP / Galmaa'i** fili; maqaa guutuu hirmaataa, bilbila, imeelii fi odeeffannoo galmee barbaachisu galchi.
3. Sagantaa kaffaltii hin qabneef unka ergi. Yoo fudhatame, paasii kennama; mirkaneessa irraa bani.
4. Sagantaa kaffaltii qabuuf qajeelfama kaffaltii sagantichaa hordofi; rasiitii kaffaltii unka galmee waliin fe'i. Mana mareen kaffaltii erga mirkaneessee booda qofa paasii seensaa kennama.
5. Lakkoofsa paasii fi imeelii kuusii. Paasii duraanii barbaaduuf **Paasiiwwan Koo** fili; imeelii fi bilbila galmee keessatti fayyadamte galchi. Paasii achi irraa buufachuu ykn maxxansuu dandeessa.

Yoo bakka guutame, haqame, ykn galmeen cufame, poortaalichi galmee haaraa hin fudhatu.

## Beeksisa sagantaa fi beeksisa biraawzari

1. Fuula Sagantaawwan irratti **Beeksisaaf Galmaa'i** ykn **Filannoowwanii fi Calallii** fili.
2. Imeelii fi/ykn beeksisa biraawzari filadhu; ramaddii sagantaa, kebele fi yeroo yaadachiisaa qindeessi.
3. Beeksisa imeeliin erguuf dura linkii siif ergamu fayyadamuun imeelii mirkaneessi.
4. Beeksisa biraawzari argachuuf hayyama beeksisaa marsariitichaaf kenni; meeshaa tokkoon tokkoon irratti beeksisa banuu fi filannoo kuusuu qabda.
5. **Qormaata Beeksisa Fageenyaa Ergi** fayyadamuun meeshaa biraawzari yeroo ammaa galmaa'e qofaaf qormaata ergi. Mirkaneessi tajaajilli push gaaffii fudhachuu isaa agarsiisa; beeksisa argachuuf kutaa beeksisaa meeshaa sanaa ilaali.

Filannoo beeksisaa bakka filannoo sana irraa jijjiiruu ykn galmee haqachuu dandeessa. Hayyama biraawzari qindaa'ina marsariitii biraawzari keetii keessatti jijjiiri.

## Arjoomaa fi herrega Zakaa

### Arjooma raawwachuu

1. [Arjoomaa](/donate) bani; maallaqa arjoomaa fi kaayyoo filadhu; odeeffannoo arjoomaa galchi. Maqaa kee dhoksuu dandeessa.
2. Mala kaffaltii tarreeffame keessaa fili; qajeelfama dabarsaa kaffaltii dubbisi.
3. Gaaffii arjoomaa mirkaneessi; lakkoofsa wabii kuusii.
4. Qajeelfama irratti agarsiifameen kaffaltii adda baasee raawwadhu; ragaa kaffaltii kee kuusii. Poortaalichi gaaffii galmeessa; mirkaneessi isaa rasiitii kaffaltii ykn kaffaltiin mirkanaa'uu isaa hin agarsiisu. Manni maree kaffaltii mirkaneessuu isaa eegii.

### Zakaa ykn Ushr herreguu

1. Herrega gubbaa irraa, fuula Tajaajiloota irraa, ykn [Arjoomaa](/donate?tab=zakat-calculator) keessaa **Herrega Zakaa** bani.
2. Maallaqa harkaa, baankii fi dijitaalaa, warqee ykn meetii, qabeenya daldalaa, invastimantii, oomisha qonnaa ykn horii irratti odeeffannoo barbaachisaa galchi. Liqii yeroo gabaabaa fi baasii jireenyaa hatattamaa ta'anis galchi.
3. Daangaa nisabii fi bu'aa herregaa ilaali. Hiika fi tilmaamaaf qajeelfama Shari'aa herregicha keessatti jiru fayyadami.
4. Madaallii seenaa keessatti kuusuu fi booda irra deebi'anii banuuf, herrega fayyadamaa seeni. Herrega ilaaluun ykn raawwachuun seensa hin barbaadu.

Herregni kun tilmaama qofaaf gargaara; kaffaltii, iyyata ofiisaa ykn murtii amantii dhuunfaa miti. Qabeenya tokko akkamitti ramaduu irratti yoo shakkii qabaatte, hayyuu gahumsa qabu ykn kutaa Zakaa mana maree gaafadhu.

## Beeksisota fi odeeffannoo Waqf

- Beeksisota barbaaduu fi dursa isaaniitiin calaluuf [Beeksisota](/announcements) bani. Geessituu fuulaa waraabuuf **Qoodi** fayyadami.
- Galmee Waqf keessatti odeeffannoo maxxanfame ilaaluuf menuu Tajaajiloota keessaa **Iftoomina Waqf** bani.

## Quunnamtii, afaanii fi salphina fayyadamaa

- Odeeffannoo kutaa quunnamtii fi gaaffilee yeroo baay'ee dhiyaataniif [Nu Qunnami](/contact) bani. Gaaffii ofiisaa erguuf maqaa fi bilbila kee galchi; gosa gaaffii fi kutaa mana maree filadhu; gaaffii kee ibsi. Imeeliin dirqama miti. Erga erguu booda lakkoofsa wabii kuusii. Haala isaa booda ilaaluuf, lakkoofsa wabii fi lakkoofsa bilbilaa yeroo galmee keessatti fayyadamte **Gaaffii Ofiisaa Hordofi** keessatti galchi; lamaan isaanii odeeffannoo gaaffii kee eegsisuuf barbaachisu.
- Afaan filachuuf filannoo afaanii gubbaa jiru fayyadami. Bifa ifaa fi dukkanaa gidduutti jijjiiruuf qindaa'ina bifa fayyadami.
- Seensi hojjettootaa hojjettoota mana maree hayyama qaban qofaaf. Tajaajiloota ummataa, galmeewwan, sagantaawwan, beeksisota fi herrega Zakaa fayyadamuuf seensa hojjettootaa hin barbaachisu.

## Lakkoofsota wabii kee eegadhu

Lakkoofsota wabii gaaffii fi iyyataa, wabii kaffaltii, lakkoofsa paasii sagantaa, akkasumas imeelii ykn bilbila iyyata keessatti fayyadamte kuusii. Linkii mirkaneessa imeelii dhuunfaa ykn linkii bulchiinsa beeksisaa nama biraatti hin qoodin.
